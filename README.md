# sprint_4
## Автоматизированные тесты для сервиса ЯндексСамокат

### Описание

Набор автоматизированных тестов на Java с использованием Selenium WebDriver для проверки двух кнопок Заказать с главной страницы и списка FAQ.
* тестирование ключевого сценария заказа самоката с заполнением всех форм двумя наборами данных с запуском сценария разными кнопками Заказать
* сверка текстов вопросов и соответствующих ответов из раздела FAQ на главной странице.

### Технологии и зависимости
* Java 11
* Selenium WebDriver 4.41.0
* JUnit 4
* Maven

### Конфигурационные параметры

URL сайта для тестов задаётся в файле src/test/java/BaseTest.java в константе URL
